# 拟合定数是什么？

[English](./fitting_level_for_players.en.md) · [完整公式](./fitting_level.zh.md)

拟合定数是以官方定数为基础、根据玩家成绩修正的难度参考。它可以略高于官方，也可以略低于官方，不能代替个人体验或官方评级。

## 怎么算？

1. 用玩家最好的 20 张成绩的平均 rating，判断玩家大致实力。
2. 比较相近实力玩家在相近官方定数谱面上的表现。最好的 20 张成绩往往代表擅长和充分练习后的发挥，不能要求玩家在每张谱面上都达到同样的表现。
3. 从其他谱面估计这种常见差距，再看目标谱面是否比同类更难拿分或更容易拿分。目标谱面不会直接参与自己的参照基准。
4. 对离群成绩降权，证据少时更接近官方定数。调整幅度用主观投票校验，避免把轻微差异放大成零点几的难度变化。

主观投票帮助校验方向和幅度，但不会直接覆盖某张谱面的拟合值。官方、成绩和投票分别提供尺度、实际表现与体验对照。

## 怎么理解结果？

- 比官方高：在可比玩家和谱面中，这张谱面相对更难取得同等表现。
- 比官方低：相对更容易取得同等表现。
- 显示 `—`：合格成绩或可供比较的其他谱面不足；不是定数为零。
- 差距很小：当前证据只支持小幅调整。没有一个适用于所有版本的“超过多少就一定虚高/虚低”阈值。

满分只说明玩家达到了分数上限，不能据此精确测量谱面难度，因此当前校准算法不使用满分成绩。玩家练习次数、偏科和选曲习惯仍会影响结果；拟合与主观意见不一致时，不能据此认定任意一方必然错误。

默认每 6 小时重算一次。当前算法在所提供的历史数据上明显减少了整体偏高，但仍有个别方向判断错误；可查看[实测结果与反例](./fitting_calibration_evaluation.zh.md)。
